문서 유형마다 대표 페이지를 직접 확인하고, 숫자·표 중심 원자료는 문서 내용 분석 대상에서 분리합니다.

분리 원칙

제외는 인벤토리 삭제가 아닙니다. 수지·통계·발행계획처럼 숫자·표를 주로 제공하는 유형은 별도 데이터 조회 수단이 더 적합하므로, 이 사이트의 문서 내용 분석 대상에서만 분리합니다.

    대표 페이지 검토

    카드를 누르면 페이지를 확대해 볼 수 있습니다. 각 유형의 포함/제외 근거를 함께 표시합니다.

    선택한 조건의 유형이 없습니다.
