    파일 수는 공개 첨부 파일 단위입니다. ZIP 파일의 내부 문서는 파일 수에 중복 합산하지 않고, 내부 문서의 측정 페이지 수만 ZIP 부모 파일에 합산합니다. 따라서 파일 수와 페이지 수의 분모는 다릅니다.
